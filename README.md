# Getaneh G. Workneh Portfolio

Personal portfolio website for Getaneh G. Workneh, Cloud Platform Solutions Architect.

## Focus

- AWS cloud and platform architecture
- Terraform, CloudFormation, and infrastructure as code
- Kubernetes, Amazon EKS, Amazon ECS, and Docker
- Backstage developer self-service platforms
- GitHub Actions and Jenkins CI/CD automation
- CloudWatch, Prometheus, Grafana, and production reliability
- Secure-by-default architecture, IAM, and secrets management

## Project Structure

- `index.html` - Responsive portfolio website
- `getaneh.jpeg` - Profile image used on the site

## Run Locally

Open `index.html` directly in a browser, or serve the folder with any static web server:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.
